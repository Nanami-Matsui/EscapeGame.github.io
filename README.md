# ごみすてだっしゅつげーむ

小学生の頃に制作した、ゴミの分別をテーマにした脱出ゲームです。  
遊びながらゴミの分別について学べることを目的としています。

---

## 概要
「ごみすてだっしゅつげーむ」は、家の中にあるゴミを正しく分別しないと脱出できない、脱出ゲーム形式の学習ゲームです。  
当時学校でゴミの分別について学び、「分別は意外と難しい」という話を家族としたことをきっかけに制作しました。

好きだった脱出ゲームの要素を取り入れ、楽しみながら分別の知識を身につけられる内容になっています。

---

## 制作背景
プログラミングは、Scratchを用いて独学で学び始めました。  
その後、大阪市の特待生として選出され、プログラミングスクールに半年間無償で通う機会を得ました。

スクールでは **HTML / CSS** を学び、それらの知識を活かして本作品を完成させました。

---

## 使用技術
- HTML  
- CSS  

---

## 作品の特徴
- 脱出ゲーム形式で、遊びながらゴミの分別を学べる
- 正しい分別を行わないとゲームを進められない仕組み
- 子どもにも分かりやすい構成とデザインを意識
